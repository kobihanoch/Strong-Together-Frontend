# Strong Together Social UI/UX mockups v5

One coherent light-mode Social UI direction based on the existing Strong Together application.

## Screen checklist

1. Home — Community with multiple crews
2. Home — no crews fallback
3. Community — Feed
4. Community — empty Feed
5. Community — Crews
6. Crews — no memberships fallback
7. Crew — active member
8. Crew — non-member
9. Crew — empty Feed
10. Search — results
11. Search — no results
12. Invitations
13. Invitations — empty
14. Create Crew (shared Create/Edit form pattern)
15. User Social Profile
16. Post / Comments

The mockups preserve the existing four-item bottom navigation. Community is entered from Home and therefore keeps Home selected.
